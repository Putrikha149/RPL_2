## Learn Dictionary python 

This is Collection type python , Dictionary. 
Consist of pair of key-value.

how to define dictionary : 

```python 
person = {
    "name":"Aries Dimas Yudhistira",
    "title":"Software Engineer",
    "last_company":"Openloop Health",
}

print(person)
```

and access some value : 

```python
print(person["title"]) # Software Engineer
```

add some new value: 
```python 
person["city"] = "Tangerang Regency"
person["salary"] = 100_000_000

print(person)
```
